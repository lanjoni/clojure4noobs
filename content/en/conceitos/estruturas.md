# Data Structures

Clojure ships a handful of useful data structures that will help you a lot. I *recommend* opening your REPL so we can try things as we go!

The basic data structures in Clojure today are: [Vectors](https://clojure.org/guides/learn/sequential_colls#_vectors), [Lists](https://clojure.org/guides/learn/sequential_colls#_lists), [Sets](https://clojure.org/guides/learn/hashed_colls#_sets), and [Maps](https://clojure.org/guides/learn/hashed_colls#_maps). The first two are *sequential collections*; the last two are *hashed collections*.

We will walk through each of them, so buckle up and let's go!
